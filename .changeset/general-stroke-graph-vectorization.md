Vectorize any handwriting as a stroke graph: loops, U-turns, junctions and
separate strokes are drawn with a minimum-retrace pen route, and every bundled
MNIST digit is fully covered. Add PNG/PNM/ASCII decoders, `vectorize` and
`serve` CLI commands, an HTTP API, a Docker image with the API server, Links
Notation export, and stroke graph, replay and image upload views in the web
app.
